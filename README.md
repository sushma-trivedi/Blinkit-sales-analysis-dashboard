Blinkit Sales Analysis Dashboard

An interactive Excel dashboard designed to analyze Blinkit sales performance, outlet characteristics, item categories, and customer ratings.

Project Overview

This project provides insights into sales trends and outlet performance using Excel dashboards and visualizations.

Key Features

* Total Sales and Average Sales KPIs
* Number of Items and Average Ratings
* Fat Content Analysis
* Item Type Sales Analysis
* Outlet Size and Location Analysis
* Outlet Establishment Trends
* Interactive filters for outlet size, location, and item type

Tools Used

* Microsoft Excel
* Pivot Tables and Charts
* Data Analysis and Visualization
* Interactive Slicers
